# cat-praise-board

✨🐱 This is a shrine dedicated entirely to worshipping the fluffiest ruler of the household... my cat! 
It lets devoted fans (me) post, search, and manage heartfelt messages of devotion. 
Built with pure love because my cat deserves his own public space to be praised.

*This is a backend practice to learn Express routing, middleware, and EJS template rendering. 
There is no custom styling applied to keep the focus entirely on server-side logic. ~~please do not tell my cat~~*

## Features
* **View Praises:** Browse all praises on the home dashboard or view a single praise on its own page.
* **Manage Content:** Full CRUD functionality to create, edit, and delete praise entries.
* **Search:** Filter praises by author name.
* **Validation & Errors:** Real-time form validation with inline error messages and appropriate HTTP status codes.

## What I Practiced
* Structuring code using the **MVC pattern** (controllers, routes, and views).
* Working with **HTTP methods** (`GET`, `POST`) and URL parameters (`req.params`, `req.query`).
* Rendering server-side dynamic views and reusables using **EJS partials**.
* Implementing **input validation & sanitization** with `express-validator` and `matchedData()`.
