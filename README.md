# cat-praise-board

This repository is a backend practice to learn Express routing, middleware, and EJS template rendering. 
There is no custom styling applied to keep the focus entirely on server-side logic.

## What I Practiced
- Setting up an Express server and routes.
- Implementing the MVC pattern (separating routes and controllers).
- Handling `GET` and `POST` requests.
- Using route parameters to display individual item details.
- Rendering dynamic server-side templates with EJS.
